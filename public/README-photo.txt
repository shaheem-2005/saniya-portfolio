PHOTO INSTRUCTIONS
1. Choose a portrait photo.
2. Copy it into this folder (public).
3. Rename the photo exactly: profile.jpg
4. Refresh the website.

The photo stays local in your project; the site uses it in the small profile section.
For best results, use a portrait image with the face centered. You can use .png too, but then
update /profile.jpg in src/App.jsx to /profile.png.
